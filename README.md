# cybersecurity-all-in-one-toolkit
Pyt# Cybersecurity All-in-One Toolkit (Python)

This project is a Python-based Cybersecurity Toolkit that combines multiple security utilities into a single application with a simple GUI.

## Features
- Port Scanner  
- Password Strength Checker  
- Hash Generator (MD5, SHA-256)  
- URL Safety Checker  

## Tech Stack
- Python  
- Tkinter  
- Socket, Hashlib, Regex  

## How to Run
1. Install Python (or Pydroid 3 on Android)
2. Run the file:hon-based Cybersecurity toolkit with multiple security utilities (Port Scanner, Password Checker, Hash Generator, URL Checker).
